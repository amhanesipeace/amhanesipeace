## 🚀 Featured projects

### 💰 [FinTrak](https://github.com/amhanesipeace/fintrak) — full-stack financial SaaS · *live*
A production-style personal-finance platform. **Flask + PostgreSQL**, JWT +
bcrypt auth, live market data (Alpha Vantage / Yahoo Finance) cached with
**Redis** and refreshed by **Celery**, containerized with **Docker**, and
deployed on Render with **Alembic migrations**.
**102 tests · ~94% coverage · CI · benchmarked performance.**
🔗 Live: https://fintrak-web.onrender.com  ·  `demo / demo123`

### 📝 [FreeNote](https://github.com/amhanesipeace/FreeNote) — free iPad notebook app
A 100% free digital notebook for iPad/iOS — **no subscriptions, ads, or
accounts**. Built with **SwiftUI + PencilKit**: markup, page templates, custom
stickers, photos, text boxes, live thumbnails, folders & search, and PDF/PNG
export. **16 tests · CI.**

### 🗣️ [Name-Pronunciation Fairness Benchmark](https://github.com/amhanesipeace/name-pronunciation-benchmark) — AI fairness research
Measures how accurately TTS systems pronounce **African-language names**
(Yoruba/Igbo/Hausa) vs English. Full pipeline (synthesize → ASR score →
analyze → **statistical tests**) across three engines, with an honest
[write-up](https://github.com/amhanesipeace/name-pronunciation-benchmark/blob/main/FINDINGS.md):
a large, statistically significant bias in the mainstream engine.

### ⚽ [EPL Insights Dashboard](https://github.com/amhanesipeace/epl-chatbot) — live sports data → stories
A live English Premier League dashboard that pulls scores/stats from sport APIs
and **auto-generates narrative insights** (title race, form, Golden Boot),
with live in-play scores, charts, and a data layer covered by **tests + CI**.
